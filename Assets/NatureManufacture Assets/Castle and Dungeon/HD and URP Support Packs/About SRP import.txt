Please import SRP packs only if your project is using HD or URP.
If you import this to the built-in project you will get errors.
Import the proper RP compatibility pack to the proper engine version:
- for Unity 6.3 URP 17.3 please use our URP 17.3 Unity 6.3 Modular Castle and Dungeon
- for Unity 6.3 HD RP 17.3 please use our HD RP 17.3 Unity 6.3 Modular Castle and Dungeon

Follow their readme!:)
